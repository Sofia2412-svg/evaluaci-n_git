# GUIA TECNICA PASO A PASO  
En este documento se hara la iniciación a los comandos principales utilizados en git yposteriormente en github, programas los cuales son la iniciación para la programación.  
## Comandos Parte 1  
Para navegar y crear, respectivamente. usamos:
- pwd: Nos da la ubicación (Directorio) en la cual estamos.  
- cd: "Change directory" Nos permite ingresar a otros directorios.  
- mkdir: Crea una nueva carpeta.  
- touch: Crear un archivo nuevo.  
## Repositorio local  
Un repositorio se inicia con el comando: "git init" que cambia la carpeta para que sea un repositorio.
