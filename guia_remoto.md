# Repositorio remotp en Github
Despues de tener nuestro repositorio para poder conectarlo a la nube debemos generar un repositorio publico en Github, dicho repositorio genera un link el cual necesitamos, luego de ellos se necesitan los tres (3) comandos principales:  
- git remote add origine "URL": Enlaza los repositorios del dispositivo con los de la nube, su usa el link generado por github  
- git branch -M: Completa el enlace  
- git push: Directamente pasa los cambios a la nube  
## Para el flujo diario  
Para mantener sincronisados la nube con el dispositivo se usan dos comandos:  
- git push: Para subir archivos del dispositivo a la nube  
- git pull: Para pasar los cambios de la nube al dispositivo
